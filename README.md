# Funny Bunny — дитячий лофт

Сайт сімейного лофту Funny Bunny (Миколаїв, Сінна 23) і студії свят «Свято кожен день».

**Сайт:** https://ttjelky.github.io/funny-bunny-loft/

## Звідки дані
Instagram [@funnybunny_niko](https://www.instagram.com/funnybunny_niko/) і [@prazdnik_kajdiy_den](https://www.instagram.com/prazdnik_kajdiy_den/) (листопад 2026):
опис лофту, хайлайти зі сценаріями, новорічний прайс, прайс на 31 грудня, благодійна вистава 5.12.

## Стиль
Мінімалістичний: тепла біла основа, фірмовий синій із постерів лофту, ніжно-рожевий другий тон,
лінійний кролик за мотивами логотипа. Шрифти Onest + курсив Lora. Статичний HTML/CSS/JS без фреймворків.

## Що уточнити в клієнтки
- Звичайний прайс: на сайті лише пакет «Стандарт» (5 500 ₴); решта слайдів каруселі без входу в Instagram недоступні.
- Фото взято з Instagram (обкладинки рілсів 640 px) — для запуску краще отримати оригінали від клієнтки.
- Описи сценаріїв написані за назвами з хайлайтів — звірити.
- Форма копіює заявку й відкриває Telegram; можна підключити бота.
