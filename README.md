# Funny Bunny — дитячий лофт

Демо-сайт для дитячого лофту Funny Bunny (Миколаїв): сценарії свят, персонажі, лофт, пакети, бронювання дати.

**Сайт:** https://ttjelky.github.io/funny-bunny-loft/

## Стек
Статичний HTML + CSS + ~5 КБ JS без фреймворків. Світла й темна тема, перемикач «Менше анімації», адаптив від 320px.

## Що замінити після погодження
- Фото лофту, свят і персонажів (зараз — ілюстративні плитки).
- Реальні назви сценаріїв і ціни (зараз — орієнтовні).
- Адресу й графік — звірити з власницею.
- Форма зараз копіює заявку й відкриває Telegram; можна підключити бота для заявок.
